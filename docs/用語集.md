### キャラクター: character

声を出している存在。複数のスタイルを持つ。
喋れるキャラクター（`/speakers` で取得）と歌えるキャラクター（`/singers` で取得）がある。
`speaker_uuid` で識別される。

### スタイル: style

キャラクターが持つ声の種類（例：ノーマル・あまあま）。
`style_id` で識別され、音声合成・歌声合成ではスタイルを指定する。

### スタイルの種類: style type

スタイルが対応している機能の種類。
`talk`・`streaming_talk`・`singing_teacher`・`frame_decode`・`sing` がある。

## エンジン周り

### speaker

「キャラクター」を指す古い名前。
API の互換性維持のため `/speakers`・`speaker_uuid`・`Speaker` などに残っているが、新しいコードでは使わない。
`/audio_query?speaker=1` のように引数名として登場する場合は、互換性のためにスタイル ID を意味する。

### talker・singer

それぞれ「喋れるキャラクター」「歌えるキャラクター」を指す。
語彙を最小限に留めるため、変更不可の API 周りを除いて極力使わず、`character` を用いる。

## OpenJTalk 周り

### フルコンテキストラベル: full-context label

文章構造を解析して得たデータを音素ごとにまとめたもの。あるいはその集合。
何の音素か、何番目のモーラか、何番目のアクセント句なのかといった情報が含まれる。
HTS の概念。

### ラベル: label

１つの音素のフルコンテキストラベルのこと。
VOICEVOX 独自の定義（OpenJTalk 内ではフルコンテキストラベルを指してラベルと呼んでいる）。

### コンテキスト: context

フルコンテキスト内の１つの要素のこと。
VOICEVOX 独自の定義。

### feature

ラベルを１行の文字列にしたもの。
OpenJTalk の概念。
